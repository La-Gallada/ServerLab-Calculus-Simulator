Título: Tasa de transferencia y área bajo la curva en [0 s; 30 s]
Descripción: Aplicación académica: datos transferidos entre t = 0 s y t = 30 s.
Variables y unidades:
- t: tiempo transcurrido (s)
- T(t): tasa de transferencia (MB/s)
- A(t): datos acumulados desde t = 0 (MB)
- D(a,b): datos transferidos en [a,b] (MB)
Parámetros utilizados:
- Límite inferior a: 0 s
- Límite superior b: 30 s
- Datos transferidos D(a,b): 240 MB
Dominio: 0 ≤ t ≤ 30 s, con 0 ≤ a ≤ b.
Modelo matemático:
- T(t) = 5 + 0,2t (MB/s), con 0 ≤ t ≤ 30
- A(t) = 5t + 0,1t² (MB)
- D(a,b) = ∫ de a a b de T(t) dt = A(b) − A(a) (MB)
Identificador del modelo: serverlab-response-transfer-v1
Versión del modelo: provisional-2026-11 (provisional)
Escala gráfica: Lineal en ambos ejes, con el eje vertical desde cero.
Resumen: La tasa pasa de 5 a 11 MB/s; el área bajo T(t) en [0 s; 30 s] equivale a 240 MB.

Nota. Elaboración propia mediante ServerLab, a partir del modelo matemático hipotético utilizado en el Proyecto de Investigación #4 de Cálculo I.
