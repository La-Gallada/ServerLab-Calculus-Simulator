Título: Tiempo de respuesta y región factible para un máximo de 500 ms
Descripción: Región de cargas que cumplen el tiempo máximo y solución entera.
Variables y unidades:
- n: usuarios concurrentes (usuarios)
- R(n): tiempo de respuesta (ms)
- L: tiempo máximo permitido (ms)
- m: máximo entero factible (usuarios)
Parámetros utilizados:
- Umbral L: 500 ms
- Carga de análisis: 65 usuarios
- Vista: enfocada
- Máximo entero: 66 usuarios
Dominio: Extensión continua 0 ≤ n < 100; la operación usa enteros de 0 a 99. n = 100 no se evalúa.
Modelo matemático:
- R(n) = 100 + 200n/(100 − n), con 0 ≤ n < 100 (ms)
- Maximizar n sujeto a R(n) ≤ L, con n entero
- Frontera continua (si L ≥ B): n* = C(L − B)/(L − B + k)
- Máximo entero: m = mín(⌊n*⌋, C − 1)
Identificador del modelo: serverlab-response-transfer-v1
Versión del modelo: provisional-2026-11 (provisional)
Escala gráfica: Lineal en ambos ejes; eje vertical de 0 a 1 000 ms, la curva continúa fuera de la vista.
Resumen: Con un máximo de 500 ms, la región factible llega hasta n* = 66,6667 y el máximo entero es 66 usuarios.

Nota. Elaboración propia del Grupo #4 mediante ServerLab, a partir del modelo matemático hipotético del proyecto de investigación.
