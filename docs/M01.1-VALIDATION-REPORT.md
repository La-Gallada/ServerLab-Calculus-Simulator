# M01.1 — Informe de validación funcional y visual

Fecha: 27 de noviembre de 2026.

## Causa del bloqueo original

La aplicación no era la causa. Las ejecuciones previas se realizaron en sandboxes distintos: cada uno tenía una ubicación temporal distinta para Chromium de Playwright y una red local aislada. Por eso Vite Preview podía anunciar su puerto pero el proceso de pruebas no podía alcanzarlo.

## Solución aplicada

- Se ejecutaron instalación de Chromium, build y Playwright fuera del sandbox, en el mismo entorno Windows.
- `playwright.config.ts` fija `127.0.0.1:4173`, Vite Preview, `--port 4173`, `--strictPort`, espera máxima de 30 s y sin reutilización de servidor.
- La prueba E2E se amplió para validar rutas, foco/teclado, sidebar móvil, assets, errores de consola, solicitudes de assets y desbordamiento horizontal.
- Las capturas se generan en el estado estable de la transición de sidebar.
